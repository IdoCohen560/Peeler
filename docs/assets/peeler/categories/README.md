# Peeler category wheel previews

These PNGs are rendered from Peeler's own `src/renderer/wheel.html`, `wheel.js`, and `wheel.css` using sample file/menu data. They are Peeler UI previews, not Tangerine screenshots.

Format wheels show the current format choices. Tools wheels list current image actions and planned actions for each file category. An asterisk marks a roadmap concept; starred choices are not implemented and cannot be run in Peeler today. Categories with more than eight actions use a second wheel page. The sample menu bridge is mocked for rendering; no conversion or tool action is executed.
