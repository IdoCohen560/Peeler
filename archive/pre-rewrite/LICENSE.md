# reference utility App - Cross-Platform Converter

This is the main executable application that demonstrates how a reference utility-like converter would work.

## Features demonstrated:
- Cross-platform file conversion (images, videos, documents)
- System integration concepts (drag-and-drop, keyboard shortcuts) 
- Minimal resource usage
- Background operation support

## How to run this app:

```bash
node legacy-app.js
```

This will execute the application and show all its capabilities.
